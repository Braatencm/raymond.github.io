Privacy Policy

Effective October 6, 2026

Raymond is a private, single-user application. The only user is the owner of the Google account that authorizes it. This policy describes how Raymond handles Google user data.

Data accessed

With the owner's permission, Raymond reads Google Calendar events and Gmail messages from the owner's own account. Access is read-only. Raymond does not send, delete or change email or calendar data.

How data is used

The data is used only to prepare summaries for the same account owner, such as a daily schedule and a list of messages that need attention.

Storage

Data is processed on the owner's own computer. Short excerpts may be sent to an AI model provider to write the summary. Raymond keeps no copy on any public server.

Sharing

Raymond does not sell, rent or share Google user data with anyone. It does not use the data for advertising. Raymond's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can revoke Raymond's access at any time at myaccount.google.com/permissions.

Contact

Questions about this policy can be sent to the support email shown on Raymond's Google sign-in screen.
